(Return) About ArcLock

ArcLock Project? is the place I decided to place all the code I have worked on in the past. Throughout my years I always though that certain things would be cool if others could use them but they were never on a scale where they warrented a full website or npm package. Now with enought of these I though it was finally a time to place them into public use. So here we are at the moment.

@artclockproject/common (Docs) (NPM)
The initial package where all code small enought might go. As of writing, includes split Video+Audio Player, PSD Viewer, Movable/Zoomable Element, AStar script, AudioManager and few other smaller components and scripts.

@arclockproject/mmd-player (Docs) (NPM)
A fully functional MMD Web Player build with babylon-mmd?.

Note: All packages contain TypeScript declarations.
